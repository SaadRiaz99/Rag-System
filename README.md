# RAG System

A Retrieval-Augmented Generation system built with Python.

## Project Structure
```
├── main.py           # Document loader
├── document/         # CSV documents
├── pyproject.toml    # Project config
└── README.md
```

## Learning Roadmap

### Week 1: Python Basics
- Variables, strings, numbers
- if/else conditions
- for/while loops
- Functions

### Week 2: Data Structures
- Lists - store multiple items
- Dictionaries - key-value pairs
- Tuples - immutable lists

### Week 3: File Operations
- Read CSV files
- Write to files
- Error handling (try/except)

### Week 4: APIs & Libraries
- OpenAI SDK
- Embeddings for semantic search
- Vector databases (FAISS/ChromaDB)

## Tips for Learning Code

1. **Write pseudocode first** - Plan in English before coding
2. **Start small** - Build one feature at a time
3. **Debug with prints** - `print(variable)` shows what's happening
4. **Copy and modify** - Start from working examples
5. **Practice daily** - 30 mins > 5 hours once a week
